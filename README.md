# Plataforma de Catálogo Digital

## Objetivo

Plataforma web de catálogo/carta digital adaptable a cualquier tipo de negocio.
Cada negocio tiene su propia instancia con su propia hoja de Google Sheets.

## Tecnologías

- HTML5
- CSS3 (mobile-first)
- JavaScript Vanilla (ES6+)
- Google Sheets como fuente de datos
- Netlify como hosting

**Sin frameworks. Sin dependencias externas.**
